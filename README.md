I've spent the beginning of my career building with statically typed languages like C# and Java as a junior software dev at a fintech, but I've always taken an interest in Python. That interest remained as curiosity for the longest time until I finally decided to stop sitting on my hands and learn it from scratch: no shortcuts, no skimming, just pure research with trial and error.

This repo tracks my step-by-step notes, code templates, and exercises as I transition into Python. I am treating every file as a complete reference note on core syntax, standard library tools, and data structures.

Why this exists
- To document my build-up (writing clear inline comments and structured examples forces me to actually understand the mechanisms instead of just guessing the output).
- To invite corrections (if you spot an error, anti-pattern, or a better way to handle something idiomatic to Python, open an issue or submit a pull request. I welcome feedback).
- To share the reference (if you are learning Python yourself, these files might help as I've fashioned them so that even my not-so technical friends can follow along).

Every directory is broken down by topic with runnable .py files. Each file includes practical, real-world data examples rather than placeholder code, showing how concepts work.
